# 교사용 예산·구매 서류 도우미

영수증(이미지·PDF)을 올리면 **자동으로 읽고**, 원본과 비교해 확인·수정한 뒤 **확정**하면
예산 잔액이 계산되고 **증빙서류를 A4 한 장으로 출력**할 수 있는 **내 컴퓨터에서 실행하는 웹앱**입니다.
(Python + Flask + SQLite. 서버나 회원가입이 필요 없고, 데이터는 내 컴퓨터에만 저장됩니다.)

## 주요 기능

- **영수증 업로드와 자동 인식**: 예산을 고르고 이미지(png·jpg·webp)나 PDF를 올리면 거래처·날짜·품목·수량·단가·금액·총액을 채워 줍니다.
- **확인·수정 → 확정**: 원본과 인식 결과를 나란히 보며 고치고, 금액은 수량×단가로 자동 계산됩니다. 확정한 지출만 예산 잔액에 반영됩니다.
- **환불 관리**: 환불을 기록하면 잔액에 즉시 반영되고, 취소도 가능합니다.
- **증빙 파일 자동 저장**: 올린 파일이 `예산명_일자_거래처.확장자`로 저장되고, 거래처·날짜를 고치면 이름도 따라 바뀝니다.
- **증빙서류 출력**: 요약표·품목표·원본을 A4 한 장으로 인쇄하거나 PDF로 저장합니다.
- **장바구니 검토 / 수기 입력**: 구매 예정 품목을 정리해 품의용 텍스트·JSON으로 복사하고, 파일 없는 거래는 직접 입력합니다.

## 준비물

- **Python 3.10 이상** (https://www.python.org/downloads/ 에서 설치). 개발은 Python 3.14에서 했습니다.
- 인터넷 (처음 설치할 때, 그리고 자동 인식을 쓸 때)
- (선택) **Upstage API 키**: 자동 인식에 필요합니다. 없어도 수기 입력·확정·환불·증빙 출력은 모두 쓸 수 있습니다.

## 실행하기

### macOS / Linux

압축을 푼 폴더에서 터미널을 열고:

```bash
bash start.sh
```

### Windows

압축을 푼 폴더의 **`start.bat`을 더블클릭**하세요. (Windows용은 직접 시험하지 못했습니다. 안 되면 아래 '직접 실행하기'를 따라 해 주세요.)

실행하면 브라우저가 열리고 **http://127.0.0.1:5002** 로 접속됩니다. 처음 실행할 때는 필요한 프로그램을 설치하느라 1~2분 걸립니다.
끄려면 실행한 창에서 `Ctrl+C`를 누르세요. (실행 중인 창에서는 다른 키를 누르지 마세요.)

### 직접 실행하기 (스크립트가 안 될 때)

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

다른 포트로 쓰려면 `FLASK_PORT=5003 python app.py` (Windows: `set FLASK_PORT=5003` 후 실행).

## 처음 사용하는 순서

1. **예산 관리 → 예산 등록**: 예산 이름·연도·배정액을 입력합니다. (예산이 먼저 있어야 영수증을 올릴 수 있습니다.)
2. **영수증 업로드**: 예산을 고르고 영수증 이미지나 PDF를 올립니다.
3. **인식 결과 확인**: 원본과 비교해 틀린 곳을 고친 뒤 초록색 **확정**을 누릅니다.
4. **지출 장부 → 증빙 출력**: 인쇄하거나 PDF로 저장합니다. 예산 현황에서 잔액을 확인합니다.

## 자동 인식 설정 (선택)

1. `.env.example` 파일을 복사해서 이름을 `.env`로 바꿉니다.
2. `UPSTAGE_API_KEY=` 뒤에 본인의 Upstage API 키를 붙여 넣습니다.
3. 앱을 다시 실행합니다.

> **개인정보 주의**: 자동 인식을 쓰면 올린 파일이 외부 서비스(Upstage)로 전송됩니다.
> 개인정보가 많은 영수증은 자동 인식 대신 **수기 입력**을 쓰세요.
> `.env`는 본인 컴퓨터에만 두고, 다른 사람에게 보내거나 Git에 올리지 마세요.

## 데이터는 어디에 저장되나요?

| 내용 | 위치 |
|---|---|
| 예산·거래·환불 데이터 | `data/app.db` |
| 올린 영수증·증빙 파일 | `storage/receipts/` |
| API 키 | `.env` |

이 세 가지는 **Git에 올라가지 않도록 설정**되어 있습니다. 백업하려면 `data` 폴더와 `storage` 폴더를 통째로 복사해 두세요.

## 시험 실행

```bash
python tests/e2e_smoke.py
```

마지막 줄에 `ALL PASS`가 나오면 정상입니다. 임시 데이터를 쓰므로 실제 데이터는 건드리지 않습니다.

## 알려진 한계

- **인식 정확도**: 흐릿한 사진, 여러 쪽짜리 PDF, 할인·포인트가 섞인 영수증은 잘못 읽을 수 있습니다. 항상 원본과 비교해 확정하세요.
- **한 사람이 한 컴퓨터에서** 쓰는 앱입니다. 로그인·권한·자동 백업은 없습니다. (여러 사람이 접속하게 열 때만 쓰는 선택형 접속 비밀번호 기능은 `.env.example`을 참고하세요.)
- 학교 서식(결재란 등)에 맞춘 한글·엑셀 내보내기는 아직 없습니다.
- PDF 원본은 증빙서류 화면의 인쇄에 포함되지 않을 수 있어, '원본만 열기'로 따로 인쇄합니다.
